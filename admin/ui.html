图片库

上传 PNG / JPG 会自动压成 WebP（原图保留）。视频也能压（会转成动图 WebP， 但注意：视频转 WebP 通常反而变大，WebP 动图的压缩效率远不如 mp4）。已存在的文件可以逐张点「⇩ 压 WebP」。 上面两个按钮直接把文件设成白天或夜晚头图。

首页大图与文案

改完记得去「构建发布」跑一次，线上才会变。

夜晚那张会在访客本地时间 20:00–05:00 自动淡入替换，切换是交叉淡出，不是硬切。

白天和夜晚各管各的，可以不一样。首屏三个文字（大标识 / 副标题 / 竖排小字）统一用这个设置。

构建与发布

只构建：生成 public/，线上完全不动，最安全。
发布走保守流程：本地预检 → 快照 public/ → 给线上现行版本打备份标签 → 普通 push（绝不强推） → 回读线上验证。
被拒绝或验证失败都会停手并保持线上原样，不会覆盖。

每次发布会自动把当时线上版本存成一个标签。出问题就点「回滚」， 它会主动切换到那个版本并推送，约 1–2 分钟生效。
